# Lurker

Sample selected 4chan boards through the read-only 4chan JSON API, generate sentiment-coloured wordclouds and chart how topics develop over time in Home Assistant.

The container image is private at ghcr.io/snorrea/lurker and requires authenticated access.

Application state and history reside in the Supervisor-managed /data volume.

Lurker is an independent project and is not affiliated with, endorsed by or sponsored by 4chan.
