# Snorrea's Home Assistant Apps

Home Assistant app definitions and versioned metadata. The Lurker source code and GHCR images remain private.

Add this repository in Home Assistant: Settings → Apps → Install app → ⋮ → Repositories.

Repository URL: https://github.com/snorrea/ha-apps

Lurker requires authorization to pull its private GHCR image before installation.

The source repository publishes this metadata only after the corresponding multi-architecture image is available.
